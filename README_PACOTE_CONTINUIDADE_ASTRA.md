# Pacote de continuidade — EUROCLIMA+ / Estrela

Pacote preparado em 17/09/2026 para a continuidade das simulações por outro
agente Codex/Astra e para a elaboração do Termo de Referência dos estudos
complementares.

## Como usar

1. Comece por `01_PROMPT_CONTINUIDADE_ASTRA.md`.
2. Leia `02_ESTADO_E_PLANO/HANDOFF.md`, `STATUS_ATUAL_PROJETO.md` e
   `PLANO_DE_ACAO.md`.
3. Trabalhe a partir de `03_MODELO_05_MODELAGEM`, preservando os arquivos
   originais e registrando novos resultados em `06_resultados`.
4. A minuta vigente é
   `04_TR_E_CONTEXTO/01_trabalho_limpo/TR_MINUTA_REV0C_LIMPA_HECRAS1D.docx`.
   A versão 0A foi preservada apenas como fonte histórica.

## Conteúdo e limites

- O pacote contém o código, dados derivados, resultados, figuras, documentos de
  contexto e camadas GIS selecionadas para reprodução e auditoria.
- As fontes raster e vetoriais brutas de grande porte permanecem no acervo
  original, indicado em `05_GIS_E_KMZ/05_referencia_fontes_pesadas/README.md`.
- Não há projeto, geometria ou plano nativo HEC-RAS pronto: essa é uma etapa
  subsequente e deve ser feita em HEC-RAS 1D.
- A análise é preliminar e não substitui estudos de viabilidade, segurança de
  barragens, licenciamento, cadastro de atingidos ou projeto de engenharia.
- Nenhuma senha, token ou credencial de banco foi incluída.

O inventário com tamanho, hash SHA-256, origem e finalidade está em
`06_INVENTARIO/manifest.csv`.
